# Project 1 — SQL + Power BI Dashboard

## Goal
Build a PostgreSQL dataset and a Power BI dashboard that answers business questions with reliable KPIs.

## Tools
PostgreSQL | SQL | Power BI

## What I built
- Created reporting-ready tables and KPI queries in SQL
- Built a Power BI dashboard with KPIs, trends, and drilldowns
- Documented definitions and assumptions in a data dictionary

## Dashboard pages
1) Executive Overview (KPIs + trends)
2) Deep Dive (region/category/customer drilldowns)

## Folder structure
- `sql/` — table creation + KPI queries
- `powerbi/` — PBIX file (optional)
- `screenshots/` — dashboard images
